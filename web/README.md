# LYRO Cut Web 0.1.0\nIndependent browser editor. Local files and IndexedDB autosave; no upload or backend. Canvas preview + Web Audio mix + MediaRecorder real-time export. MP4 if supported, otherwise WebM. 4K experimental; browser codecs, filter support, frame pacing and memory limits vary. Not binary-compatible with native projects. Serve this folder as static site.\n
## 0.4.0 Studio Foundation
Mac-inspired workspace, resizable panels, persistent layout widths, workspace modes, dynamic tracks, locks/mute/visibility, markers, multi-select/group moves and shared .lyrocut format v1. Unsupported effects and image/demo projects are rejected by the interchange adapter; .lyroweb is still supported. Native and browser render engines remain distinct. Export is still browser real-time MediaRecorder.\n
## 0.5.0
Professional frame-based ripple, roll, slip and slide with atomic validation, same-track cross-dissolves, and shared editing tests. Multicam, proxy workflows, nested sequences and deterministic frame-by-frame export remain pending.

## 0.5.1 Settings
Persistent project defaults, source matching, track density, snap distance, undo limit, preview cap, export preferences, optional local recovery and keyboard reference. Browser codec availability still determines supported export types.

## 0.6.0 Color & FX
29 Canvas effects, categorized search and editable ordered stack with strength, mix, enable/bypass, detail and angle where applicable. Cross-platform supported effect IDs are portable; renderer appearance can differ. Advanced settings for projects, FX, monitoring, performance and export. Effects use the same canvas for preview and realtime export; heavy CPU filters may affect frame pacing.

## 0.6.1
35 visual effects, 16 built-in multi-effect looks, saved local presets, and reusable effect stacks. Browser edition updates via deployment; reload when not editing to obtain the new version.
