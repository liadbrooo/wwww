# LYRO Cut Windows 0.7.0 — Foundation
Local Tauri 2 / Rust application embedding the existing Studio UI (no remote website). NSIS current-user installer, custom brand artwork and portable EXE zip. Windows 11 x64, WebView2 required. No code signing yet.

The existing multitrack canvas editor, FX, local projects and browser-style export are available in the embedded WebView. The new Rust native renderer supports contiguous V1 clips with source trim, basic color correction, volume and H.264 MP4 export, up to 3840x2160. Additional effects, titles, transforms, multiple tracks and speed edits are intentionally rejected by this limited native path; use the regular canvas export. FFmpeg and FFprobe must be installed separately (e.g. winget install Gyan.FFmpeg); they are not redistributed. NVENC is experimental, requires compatible drivers and FFmpeg build. No hardware benchmark yet. Native export requests source relinking, uses validated parameters, no shell, and stages output locally. Installer requires internet only if WebView2 missing. Actual desktop interaction, long-project stability, full native compositing, signed updater and proxy/caching remain 0.7.x work.

Build on Windows with Node 22, Rust stable, Visual Studio C++ build tools, Python Pillow: python windows/brand.py; cd windows; npm install; npm run build. CI tests the Rust rendering path including UHD and creates the installer.

## 0.7.1 — Windows Updater
Update settings, automatic checks at startup and configured intervals while running, semantic version selection of stable Windows releases only, native HTTPS download, SHA-256 and expected release size verification, native project backup dialog before installer launch. Normal interactive NSIS setup is launched and the editor exits. No Authenticode or independent signed manifest yet; trust relies on GitHub release publishing. Portable builds transition to installed edition via setup; direct portable self-replacement is not implemented. Full upgrade cycle requires a subsequent Windows release and real machine testing.
